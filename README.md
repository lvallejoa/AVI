# Agentes Virtuales Inteligentes como Soporte Cognitivo para Mandos Gerenciales en Organizaciones Corporativas

**Curso:** PF-3311 Agentes Virtuales Inteligentes — Universidad de Costa Rica  
**Investigador:** Luis Vallejo Astúa | I Ciclo, 2026

---

## Descripción

Este proyecto propone el diseño, desarrollo y evaluación de un Agente Virtual Inteligente (AVI) corporizado con reconocimiento y síntesis de voz impulsados por LLMs, conectado a fuentes de datos empresariales mediante una arquitectura RAG. El objetivo es reducir la carga cognitiva de mandos gerenciales en tareas rutinarias de coordinación, comparando su efectividad frente a un chat de texto tradicional.
